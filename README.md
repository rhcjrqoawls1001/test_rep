# Git 협업 연습

두 사람이 이슈 → 브랜치 → 커밋 → 푸시 → PR → 리뷰 → 병합 → 충돌 해결을 한 바퀴 돌아보는 연습용 저장소입니다.

진행 방법은 [연습가이드.md](연습가이드.md) 를 보세요.

| 파일 | 내용 |
|---|---|
| `config.py` | 설정값 (유예 시간 등) |
| `rules.py` | 2인 1조 판정 함수 — 쓰러짐 처리가 비어 있음 (이슈 #1) |
| `check.py` | `rules.py` 검사. `python check.py` |
| `team.md` | 팀 소개 · 소감 (충돌 연습용) |
